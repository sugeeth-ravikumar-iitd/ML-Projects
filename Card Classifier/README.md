# Card Classifier

A machine learning project for classifying card combinations based on hand features.

## Overview

This project explores classification techniques for identifying different card hand categories. The workflow includes data preprocessing, model training, evaluation, and performance analysis.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Dataset

[Poker Hand Dataset](https://archive.ics.uci.edu/dataset/158/poker+hand)
